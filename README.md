# Valheim Mods

Small Valheim mods that fill gaps in the vanilla game. Every mod is built from the game's own models, textures and effects.

## Installing

All mods need [BepInExPack Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/).

- **With a mod manager:** most Valheim mod managers can import a mod from a local zip. Import the downloaded zip as it is; don't unpack it.
- **By hand:** install BepInExPack Valheim, unpack the zip, and copy the `.dll` files from its `plugins` folder into `BepInEx\plugins` in your Valheim folder.

## Multiplayer

Read the notes on each release page. In short: everyone needs the same version of each mod. A dedicated server doesn't need them, but installing them there is recommended: a server without a mod deletes that mod's items left on the ground, or saplings planted, near the centre of the world.
